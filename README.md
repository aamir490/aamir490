The platform combines multiple specialized AI agents into a single workspace for chat, coding, web search, vision, PDF RAG, document generation, image generation, and more.

### Key Capabilities

* 🤖 Multi-agent AI workflows
* 🗨️ AI chat
* 🔍 Web search
* 💻 Code generation
* 📚 PDF RAG
* 🖼️ Image analysis
* 🎨 Image generation
* 📄 PDF generation
* 📊 PowerPoint generation
* 🔐 Google authentication
* 💳 Credit-based billing
* 👑 Admin dashboard

### Technology

## 🧾 2. NovaMind AI — Invoice Intelligence Platform

An **AI-powered serverless invoice processing platform** built on AWS.

The system processes invoice documents, extracts structured information, performs AI-powered anomaly detection, calculates risk scores, and presents the results through a React dashboard.

### Key Capabilities

* 📄 Invoice document processing
* 🔍 OCR and structured data extraction
* 🤖 AI-powered anomaly detection
* 📊 Risk scoring
* 📈 Analytics dashboard
* 🔐 Cognito authentication
* 🚨 High-risk invoice notifications
* ⚡ Event-driven serverless processing

### Technology

`React` • `TypeScript` • `Python` • `Vite` • `Tailwind CSS` • `Zustand` • `React Query`

### AWS Architecture

`Amazon S3` → `SQS` → `Lambda` → `Step Functions` → `Amazon Textract` → `Amazon Bedrock` → `DynamoDB`

Additional services:

`CloudFront` • `API Gateway` • `Cognito` • `EventBridge` • `SNS` • `CloudWatch` • `X-Ray`

### Infrastructure & CI/CD

`AWS CDK v2` • `TypeScript` • `GitHub Actions` • `OIDC`

🔗 **Repository:**
https://github.com/aamir490/Use-Case-14-NovaMind-AI-Invoice-Intelligence-Platform-AWS-CloudFront

The repository documents the complete event-driven invoice pipeline, including Textract extraction, Bedrock Nova Micro analysis, deterministic risk scoring, DynamoDB persistence, and EventBridge/SNS alerting.

## 📈 3. NovaMind — Real-Time AI Sentiment Analytics

An end-to-end **real-time AI analytics platform on AWS** using streaming data, Apache Flink, Amazon Nova AI, and OpenSearch Serverless.

The platform processes independent movie-review and financial-commentary streams and enriches records with AI-powered sentiment classification.

### Key Capabilities

* ⚡ Real-time streaming analytics
* 🤖 AI-powered sentiment classification
* 📊 Live Streamlit dashboards
* 📈 Sentiment trends and distributions
* 🎯 AI confidence scoring
* 🔎 OpenSearch analytics
* ☁️ Infrastructure as Code with CloudFormation

### Technology

`Python` • `Apache Flink` • `Streamlit` • `boto3` • `AWS CloudFormation`

### AWS Architecture

`EC2` → `Amazon Kinesis` → `Amazon Managed Service for Apache Flink` → `Amazon Bedrock / Nova Lite` → `CloudWatch` → `Lambda` → `OpenSearch Serverless` → `Streamlit`

Additional services:

`IAM` • `SSM` • `SNS` • `VPC`

🔗 **Repository:**
https://github.com/aamir490/Use--Case--17--NovaMind-Real-Time-AI-Sentiment-Analytics-CloudFormation

The repository documents two streaming pipelines, Amazon Nova Lite sentiment classification, Kinesis streams, Managed Flink applications, OpenSearch Serverless, Lambda processing, and Streamlit dashboards.
